### Verification details / 審核限制

- The source **publisher page**, identity of the object, and listed credit have been checked for ESO/Esa-Hubble pictures above; NASA/ESA media usage guidelines and original NASA image page claims have been cross-checked for important photographs. Individual remote image files could still fail to load due to hotlink blocking, host changes, or network policy.
- NASA/ESA image files are **not bundled** in this repository: they are requested at runtime; this does **not** automatically grant unrestricted redistribution.
- Specific NASA evidence: the previous `voyager1` photo was PIA21736 **Voyager 2**, so it was replaced by PIA21740 **Voyager 1 Golden Record installation**. Saturn was corrected to PIA17218 showing the full globe and rings. The Sun uses the actual NASA SVS file name.
- The archival **ESA Giotto image** is not Creative Commons or MIT; it is linked to ESA media-use conditions in the card.
- Images with no photograph still display a scientific reference link; no photograph is falsely claimed.
- The code is a visual model rather than an accurate scale or ephemeris; see [SCIENCE_NOTES.md](SCIENCE_NOTES.md).
