# GitHub 首次發佈指引 / First Publication

建議專案名稱 / Suggested repository name: `galaxy-solar-system-motion-lab`

## 上傳

1. 先完成 `ASSETS_CREDITS.md` 所列的素材來源及逐圖署名檢查。
2. 前往 https://github.com/new。
3. Repository name: `galaxy-solar-system-motion-lab`；Visibility: **Public**。
4. 建立**空白 Repository**（不要另外生成 README / LICENSE，以免上傳後重複）。
5. 解壓整個 ZIP，將資料夾內**所有內容**（包含 `index.html`、點號開頭的 `.nojekyll` 及 `.github` 資料夾）上傳至 Repository **根目錄**；不要只上傳 ZIP。
6. Commit message 可以用 `Initial open-source release v1.0.0`。
7. Repository → **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** → Folder: **/(root)** → Save。
8. 發佈後打開 Pages 顯示的網址，測試：太陽初始視角、語言切換、地球／土星、資料卡照片、獵戶座腰帶、光軌與格線開關。

依照 GitHub 文件，站點第一次部署可能需要幾分鐘。GitHub Pages 公開網址可由 Repository Settings → Pages 取得。

## 發佈前必檢 / Mandatory pre-publication checks

- [ ] 你有權將原創程式碼以 MIT 授權公開。
- [ ] 所有**內嵌**的影像貼圖已確認來源與重用權利，並署名。
- [ ] 確認官方影像檔各自所列的完整 credit；CC BY/CC BY-SA 依條款署名及連結授權。
- [ ] 外部照片無誤用權利不明的第三方轉載網址。
- [ ] 沒有密碼、API Key、Token、私人資料或隱藏管理功能。
- [ ] 在 Chrome／Edge 完成 WebGL 實機測試。
- [ ] 域名、Repository、GitHub Pages 成功公開（不要只依賴 ZIP）。

## English quick steps

1. Verify media provenance and exact per-image credits.
2. Create a new **Public** repository at https://github.com/new named `galaxy-solar-system-motion-lab`.
3. Upload **the extracted files** from this release ZIP to the repository root, not the ZIP itself.
4. Enable **Settings → Pages → Deploy from a branch → main / (root)**.
5. Test the publicly deployed URL and repository file structure.
6. Confirm code ownership and MIT licensing, external photo credits and absence of secrets.
