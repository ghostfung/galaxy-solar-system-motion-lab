# Changelog

## [1.0.0] — Release candidate (2026-11-04)

- Prepared V11 as an open-source repository with bilingual documentation.
- Preserved the existing single-file simulator, astronomy controls and Orion's Belt features.
- Documented the separation between MIT-licensed project code and third-party media.
- Replaced selected third-party image mirrors with original NASA/ESA/Hubble/ESO source images and credits.
- Added scientific limitations, media provenance, contributor guidance and GitHub Pages publishing instructions.
- Corrected Orion's Belt star rendering so Alnitak, Alnilam and Mintaka read as blue stars instead of nearly white glows.

**This is a proposed first public version, not a claim that a GitHub release or GitHub Pages site exists.**
